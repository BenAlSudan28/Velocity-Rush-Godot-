# Velocity Rush 3D

Godot 4.4.1 Android racing game. This project includes a procedural city racing environment, bundled offline audio, touchscreen controls, cockpit/chase cameras, and six bundled glTF 2.0 (`.glb`) stylized 3D vehicle models.

## Vehicle models

The models in `assets/vehicles/` are original stylized models inspired by broad sports-car categories. They are not official manufacturer models or photorealistic licensed assets.

## Build

The project retains its existing GitHub Actions workflow. Upload the contents of this directory to the repository root and run **Build Velocity Rush 3D APK** from Actions.

## Important scope notes

- `DUEL RACE / VS AI` means a race-style mode against the game's AI traffic/opponents; it is not online multiplayer or split-screen multiplayer.
- Audio and visual resources are bundled locally; no network is required while playing.
- This package has not been run in the Godot engine in the current environment. Build and test the APK with GitHub Actions before release.
