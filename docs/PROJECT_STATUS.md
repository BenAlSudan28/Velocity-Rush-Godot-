# Velocity Rush 3D

## Project

An original 3D arcade racing game for Android.

## Engine

Godot Engine 4.4.1

## Minimum Android Version

Android 10 (API 29) is the intended minimum.

The final exported APK must be checked to verify its minimum SDK.

## Current Prototype

The initial prototype includes:

- A generated 3D road.
- A player vehicle.
- A chase camera.
- Basic opponent vehicles.
- Steering buttons.
- Nitro control.
- Braking.
- Basic collision detection.
- A score counter.
- Pause and restart controls.

## Current Limitations

The initial prototype uses procedural geometric car models.

It does not yet include:

- High-detail imported vehicle models.
- Professional vehicle textures.
- Recorded engine sounds.
- Recorded collision sounds.
- Advanced vehicle physics.
- Curved road generation.
- Career progression.
- Multiple race tracks.
- Online multiplayer.

## Build

The GitHub Actions workflow attempts to export a debug APK.

The exported APK is available as a workflow artifact only after a successful build.
